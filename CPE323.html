Lecture 2: Stack Memory and Addressing Modes

Physical address = (Segment register × 10H) + Offset

Multiplying by 10H shifts the 16-bit segment register one hex digit left, giving a 20-bit base. The offset (BX, DI, BX+DI, a displacement and so on) is then added. Example: DS = 2000H and offset 0206H give 20000H + 0206H = 20206H.

Standard 8086 rules, not in the lecture notes: BX, SI, DI and direct addresses default to DS. BP defaults to SS. Stack operations use SS:SP.

Little Endian Rule

When a 16-bit word is read, the low byte comes from the lower address and goes into AL or DL. The high byte comes from the higher address and goes into AH or DH. If 10000H holds FF and 10001H holds 02, the register becomes 02FFH.

Stack (LIFO)

  • PUSH: SP = SP − 2, then write 16 bits.
  • POP: read 16 bits, then SP = SP + 2.

Lecture 3: Program Control and Flags

CMP AX,BX subtracts BX from AX and sets the flags. AX and BX stay unchanged. The lecture lists the C, Z, S and O flags, and the 8086 also sets P and A.

Quick Reference

Top Traps

  1. Reversing the Little Endian byte order.
  2. Changing AL and accidentally wiping AH, or the reverse.
  3. Treating ADD DS,2000H as legal. Segment registers cannot take an immediate value. Load them through a register: MOV AX,2000H, then MOV DS,AX.
  4. Mixing up the first and last execution of a loop body.
  5. Thinking CMP changes its operands.
  6. Thinking IP holds the current instruction.

4. Execution Table (Q1 to 20, 70 points)

Starting values from the paper: DI = 0200H, SI = 0400H, DS = 2000H. AX, BX, CX and DX start at 0000H. Each row number is a program line. A question about the 9th instruction means row 9. First and last execution are the first and last times that row runs.

#InstructionNotes
Watch out for wrap-around. DEC on 0000H gives FFFFH and clears the zero flag, so JNZ jumps back to row 8 instead of exiting. Track CX carefully once it reaches zero.

How to Trace Each Row

  1. Keep a running state table with one row per execution and all nine columns. Copy unchanged values straight down.
  2. For each memory operand, work out the effective address: BX + DI + displacement, SI, or a direct number.
  3. Physical address = DS × 10H + EA. BP would use SS instead.
  4. Word reads follow Little Endian: the low byte comes from PA and the high byte from PA+1.
  5. Byte operations change only the named half. AL changes alone and AH keeps its value.
  6. ADD, ADC, DEC and CMP set the flags. MOV does not. Mark illegal rows and leave their registers unchanged.

5. Memory Map (10 points)

The paper asks for the physical addresses and results of the memory-changing rows: 10, 14, 22, 26, 34 and 38. Each is a MOV [SI], register instruction, so PA = DS × 10H + SI, using the SI value at that moment.

A word store writes the low byte to PA and the high byte to PA+1. Example: with DS = 2000H and SI = 0410H, MOV [SI],AX writes AL to 20410H and AH to 20411H.

6. Practice and Corrections

Correction to the lecture notes: the original 32-bit addition example gave AX = DDDEH and a result of 1 1110 DDDEH. The correct low word is DDE0H, because DDDD + 0003 = DDE0. The final result is 1 1110 DDE0H.

Adding Two 32-bit Numbers on the 8086

Problem: add 4444DDDDH and CCCC0003H. The ALU is 16 bits wide, so split each number into a low word and a high word. Add the low words with ADD, then add the high words with ADC so the carry is included.

MOV AX, DDDDH    ; low word of first number
MOV BX, 0003H    ; low word of second number
ADD AX, BX       ; AX = DDE0H, carry flag = 0
MOV CX, 4444H    ; high word of first number
MOV DX, CCCCH    ; high word of second number
ADC CX, DX       ; CX = 4444H + CCCCH + 0 = 1110H, carry flag = 1

Result: CX:AX = 1 1110 DDE0H. Crosscheck: 4444 DDDDH + CCCC 0003H = 1 1110 DDE0H.

Practice Problem

Add 12345678H and 9ABCDEF0H the same way. Try it before you check. Answer: ACF13568H. The low words give 3568H with a carry of 1. The high words give 1234H + 9ABCH + 1 = ACF1H.

Potential Exam Questions

Short, near and far jumps. A short jump is a 2-byte instruction with a 1-byte displacement (−128 to +127 bytes). A near jump is a 3-byte instruction with a 2-byte displacement (up to ±32 KB). Both change only IP. A far jump is a 5-byte instruction carrying a new CS:IP address, so it changes both CS and IP.

SP after PUSHA, starting from SP = 1000H. PUSHA pushes eight 2-byte registers, so SP = 1000H − 10H = 0FF0H. PUSHA belongs to the 80186 and later, not the 8086. On an 8086 you would use eight PUSH instructions and reach the same SP.

LOOPZ vs LOOPNZ. Both decrement CX. LOOPZ repeats while CX is not 0 and ZF = 1, which suits checking that every element matches. LOOPNZ repeats while CX is not 0 and ZF = 0, which suits searching for a target.

Quick Drills

  1. SP = 1000H, then PUSH AX, PUSH BX, POP CX. What is SP at the end? 0FFEH. Two pushes take SP to 0FFCH, and the pop brings it back to 0FFEH.
  2. DS = 2000H, BX = 0100H, SI = 0010H. What is the physical address of MOV AL,[BX+SI]? 20110H.
  3. Which table rows write to memory? Rows 10, 14, 22, 26, 34 and 38.
